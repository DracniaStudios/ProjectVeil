[ Issues ]



[ Added ]

- Added Collider3D, a collision volume authored independently of the render scale.
  Shapes: Box, Sphere, and Mesh (auto-fitted to the loaded model's own bounds).
- Added Collider modes. Collision resolves through the Rigidbody as before;
  Trigger reports the overlap and applies no physics at all - no push, no
  impulse, no friction, and no touch flags, so a trigger cannot be stood on.
- Added GameObject::onTriggerEnter / onTriggerExit. onCollision still fires for
  triggers as well, so existing listeners are unaffected.
- Added a Collider section to the Object Browser (shape, mode, size/radius,
  offset, Fit To Model, Reset Collider) and staged shape/mode in the Placement
  Panel, so a trigger volume can be dropped in directly.
- Added tests/ColliderTests.cpp (99 checks, links raylib alone) and
  tests/TriggerTests.cpp (11 checks, links the engine).
- Added ColliderRaycast, an exact ray test for every collider shape, and
  RigidBody3D::Raycast / OverlapsBroadPhase in front of it.

[ Updated ]

- Moved all Engine specific files to "engineLayer" folder.
- Updated GameMap to hold all Entity and Interactables data.
- Updated RigidBody3D so the narrow phase, the broad-phase box, the touch rays
  and the debug draw all read one resolved collider volume instead of `scale`.
  Defaults reproduce the old numbers exactly, so worlds saved before this load
  and behave identically and no save version bump was needed.
- Updated the 15-axis separating-axis test to live in Collider3D.cpp, which has
  no engine dependency and so can be unit tested against raylib alone.
- Updated Show Collider to draw the actual collider, coloured by mode, rather
  than the render scale. Spheres draw as spheres.
- Updated sound occlusion and stalker line of sight to see through triggers. A
  damage zone across a corridor no longer muffles footsteps or blinds the AI.
- Updated mesh bounds to finally reach collision, via Collider3D::FitToModel in
  loadVisuals(). They were previously computed and discarded every frame.
- Updated every ray test that decides something - grounding and the touch flags,
  stalker line of sight, sound occlusion, and the interaction crosshair - to run
  against the collider instead of the box around it. A rotated ramp, an offset
  collider or a sphere all sit inside their own bounds, and a ray through that
  gap was a miss being reported as a hit.
- Updated RigidBody3D::collisionBox to broadPhaseBox, and SyncCollisionBox to
  SyncBroadPhaseBox. It is not the collision shape, it is a conservative bound
  around it, and the old name invited exactly the misuse above. Broad-phase
  gates now read a.OverlapsBroadPhase(b) so a gate looks like a gate.
- Updated the editor's ray/box slab test to live with the collider maths, so the
  editor and the game share one implementation. Picking still tests the visual
  box rather than the collider, so shrinking a collider cannot make an object
  unclickable.

[ Fixed ]



[ Removed ]

- Removed Entity and Interactable data from Scene.
- Removed RigidBody3D::collisionBoxScale, declared for a collider offset and
  never read by anything. Collider3D::size and ::offset replace it.
- Removed RigidBody3D::GetWorldAxes, which had no callers left once the resolved
  collider volume carried the axes.
- Removed the two GetMeshBoundingBox assignments in GameObject, which wrote a
  model-local box into a world-space field that SyncBroadPhaseBox overwrote.
- Removed RigidBody3D::GetColliderBox, which had no callers and named the
  collider while returning the broad-phase box.
