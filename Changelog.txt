[ Added ]

- Added an Overlay Stack to each Scene (Title, Inventory, Settings, Multiplayer, MiniGame).
	It decides which overlay has the player's input, and only the top one draws its panel.
- Added MiniGameSession. It starts minigames, retries a lost round at the same station,
	and reports a win with its game and station.
- Added a Target to Task stations. Winning at a station toggles its Target (none toggles the station itself).
- Added Pick Target and Clear Target to the Object Browser, and an outline on a selected station's Target.
- Added Win, Retry and Quit to the MiniGame Inspector.
- Added Close All Overlays to World Settings, with a read-only list of open overlays.
- Added OverlayStack and MiniGameSession tests.
- Added CONTEXT.md for game terms (Overlay, Title, Inventory, MiniGame, Task station, Target, Practice run).
- Added one GameMap lifecycle for every kind of object: Spawn, Restore, Destroy and Clear.
	GameMap now owns the ids, and Scene::ClearWorld empties the world and the player's inventory together.
- Added GameMap tests for Spawn, Restore, Destroy and Clear.
- Added a PhysicsWorld that resolves every pair of bodies in one pass, player included,
	and reports each contact's start and end with both bodies' ids.
- Added ContactRules for impact noise, Stalker contact damage and projectile damage, read from those contacts.
- Added PhysicsWorld tests, which run without a window.
- Added one save pipeline for Game saves and World saves: one Snapshot and one Apply,
	with the save's scope deciding what it holds.
- Added SaveStore, which keeps saves by name in files or in memory, and SaveParticipant,
	which keeps a section held outside the Scene, such as Lighting.
- Added SaveSystem tests, which round-trip every kind of object through files and through memory.

- Updated Destroy to wait until the end of the frame for entities and interactables too, as it already did for GameObjects.
- Updated the player's inventory to hold item ids instead of pointers.
- Updated GameObject to create its model when it enters the world, not in its constructor.
- Updated touch flags (standing, walls) to come from every solid body, not only plain GameObjects.
- Updated TriggerTests, EmitterTests and StalkerContactDamageTests to run the real collision solve
