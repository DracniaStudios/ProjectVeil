[ Added ]

- Added an Overlay Stack to each Scene (Title, Inventory, Settings, Multiplayer, MiniGame).
	It decides which overlay has the player's input, and only the top one draws its panel.
- Added MiniGameSession. It starts minigames, retries a lost round at the same station,
	and reports a win with its game and station.
- Added a Target to Task stations. Winning at a station toggles its Target (none toggles the station itself).
- Added Pick Target and Clear Target to the Object Browser, and an outline on a selected station's Target.
- Added Win, Retry and Quit to the MiniGame Inspector.
- Added Close All Overlays to World Settings, with a read-only list of open overlays.
- Added OverlayStack and MiniGameSession tests.
- Added CONTEXT.md for game terms (Overlay, Title, Inventory, MiniGame, Task station, Target, Practice run).
- Added one GameMap lifecycle for every kind of object: Spawn, Restore, Destroy and Clear.
	GameMap now owns the ids, and Scene::ClearWorld empties the world and the player's inventory together.
- Added GameMap tests for Spawn, Restore, Destroy and Clear.
- Added a PhysicsWorld that resolves every pair of bodies in one pass, player included,
	and reports each contact's start and end with both bodies' ids.
- Added ContactRules for impact noise, Stalker contact damage and projectile damage, read from those contacts.
- Added PhysicsWorld tests, which run without a window.
- Added one save pipeline for Game saves and World saves: one Snapshot and one Apply,
	with the save's scope deciding what it holds.
- Added SaveStore, which keeps saves by name in files or in memory, and SaveParticipant,
	which keeps a section held outside the Scene, such as Lighting.
- Added SaveSystem tests, which round-trip every kind of object through files and through memory.
- Added SceneManager_frame and SceneManager_tick. A frame runs the fade, the camera, the Inventory key
	and the World Editor; a tick runs the scene's simulation.
- Added a scene factory to SceneManager, so tests can switch scenes without a world file or music.
- Added a description to every setting: its kind (Toggle, Choice or Range), its label, its page in the menu and its default.
- Added Settings tests, which need no window and no library but JSON.
- Added World lighting and Setting to CONTEXT.md: a world owns its lighting, and a Setting only changes how it is shown.

[ Updated ]

- Updated TAB to be the Inventory key. It opens the Inventory during gameplay,
	closes the top overlay otherwise, and quits a running minigame.
- Updated the Main Menu to open its Title and fix the camera, so the player can't walk or look around behind it.
- Updated the cursor to lock during gameplay and unlock for any overlay or the World Editor.
- Updated the six MiniGames to own their state and cursor, and return Running, Won or Lost instead of freeing themselves.
- Updated Settings and Multiplayer to hide the Title panel instead of drawing over it.
- Updated RigidBody2D to stay inside a bounds rectangle instead of the window.
- Updated Task station saves to write "TargetId". Older saves take it from "Activator".
- Updated the Placement panel's "Activator ID" to "MiniGame Target".
- Updated the Title panel to draw from UI/Overlays.cpp instead of mainMenu.cpp.
- Updated Destroy to wait until the end of the frame for entities and interactables too, as it already did for GameObjects.
- Updated the player's inventory to hold item ids instead of pointers.
- Updated GameObject to create its model when it enters the world, not in its constructor.
- Updated touch flags (standing, walls) to come from every solid body, not only plain GameObjects.
- Updated TriggerTests, EmitterTests and StalkerContactDamageTests to run the real collision solve
	instead of a copy of it.
- Updated SaveGame, LoadGame, SaveWorld and LoadWorld to run through that one pipeline.
	They keep their names, files and messages.
- Updated loading to check the whole save before it clears the world.
- Updated Lighting to be saved as a participant instead of SaveSystem writing it directly.
- Updated scene update and draw functions, Player, interactables, Entity's Attack, AudioManager and the World Editor
	to be handed the Scene they work on, instead of reading SceneManager's current scene. Only the main loop reads it now.
- Updated a new scene to become current only once it is fully built.
- Updated the fade between scenes to last 0.85 seconds each way at any frame rate. Below 60 FPS it used to take longer.
- Updated SceneTransitionTests to run through SceneManager_frame and SceneManager_tick with their own scene factory.
- Updated the Settings menu to show one page at a time (Gameplay, Display, Video, Sound),
	with each value in its own words: On, Ultra, 75%.
- Updated a press on a setting to move it on as its kind says: a Toggle flips, a Choice moves to its next option,
	and a Range steps up, each going back to its first value after its last.
- Updated Settings to save every change as it is made, and to tell Audio and Lighting at once.
- Updated volume changes to reach sounds already playing from files, such as the Main Menu music.
	FMOD events take the new volume the next time they start.
- Updated Settings to be kept through a SaveStore, like Game saves and World saves. settings.json keeps its name and keys.
- Updated loading settings to keep the default for any value a setting can't hold as written, such as Luminosity 0.
- Updated Lighting to belong to each world, so every scene can be lit its own way. The player's Shadows setting
	can switch shadows off or draw a smaller shadow map, and Luminosity scales the world's exposure;
	neither changes what the world's save holds. A world never gets a bigger shadow map than it was saved with.
- Updated the shadow map to be resized at the start of the next frame, not at the moment a setting or the Lighting panel changes.
- Updated the Lighting panel to show the shadow map being drawn and the player's limits beside the world's own values.
